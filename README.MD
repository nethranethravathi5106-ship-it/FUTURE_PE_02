AI UGC Ad Content Generator

Task 2 — Future Interns

An AI-powered prompt system designed to generate engaging, UGC-style advertising content for social media platforms.

Objective

The goal of this project is to create a reusable prompt system that generates authentic, attention-grabbing advertisements for different brands and products.

The system follows a Problem → Solution → CTA structure and adapts the content for different social media platforms and brand tones.

Content Generated

The prompt system generates:

- Attention-grabbing hooks
- UGC-style ad scripts
- Problem → Solution → CTA scripts
- Instagram advertisements
- Facebook advertisements
- YouTube Shorts advertisements
- Social media captions
- Call-to-action variations

Brand Tones

The system can adapt advertisements to different tones, including:

- Friendly
- Casual
- Professional
- Energetic
- Emotional
- Trendy
- Humorous

Platforms

The generated content is optimized for:

- Instagram
- Facebook
- YouTube Shorts
